## 功能

### 编辑器

- [x] 进行基本编辑
- [x] 使用多光标进行快速编辑（需按住 Alt 键）
- [x] 所在行高亮
- [x] 自动分词

### 评测

- [x] 自定义评测点

### 设置

- [x] 深浅色主题切换
- [x] 自定义主题色
- [x] 编译选项控制
