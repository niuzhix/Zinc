<br/>
本应用的名字灵感源于 锌元素。

## 功能

> [!Tip]
> 您可以点击查看 [Zinc 文档](https://zinc.niuzhix.dpdns.org) 了解更多。

### 代码编辑

- [x] 支持 C++ 语法高亮、括号匹配、自动缩进、行号、当前行高亮、多光标编辑
- [x] 查找替换、字体缩放、Tab 转空格
- [x] 自动保存、崩溃恢复、会话恢复

### 本地评测

- [x] 评测结果判定：AC / WA / TLE / MLE / RE / CE
- [x] 自定义时间限制、内存限制，显示评测耗时
- [x] 查看每个测试点的输入、输出、期望输出与错误信息

### 编译与运行

- [x] 自定义编译参数、优化等级、C++ 标准
- [x] 编译错误/编译日志面板/编译超时处理
- [x] 运行与输出查看
- [ ] GDB 单步调试（即将发布）

### 配置与界面

- [x] 主题系统：内置多主题，支持自定义配色

## 开始使用

**首先，请确保您的设备满足以下推荐需求：**

- Windows 10 或更高版本
- Debian（或其衍生版）10 或更高版本，X11 图形环境

> [!IMPORTANT]
> **详细安装说明请参阅 [ClassIsland 文档](https://zinc.niuzhix.dpdns.org/get-started/setup)。**
>
> 不建议在 Windows 10 以下的系统运行本应用。在 Windows 7 中，.NET 运行时会产生**严重的内存泄漏问题**。
>
> 要在 Linux 中安装并运行本应用，需要 X11 桌面环境，不支持 Wayland。通过 XWayland 运行不属于 Zinc 的支持范围，部分功能可能无法正常运行。

对于普通用户，可以在以下渠道下载到本软件，请根据自身网络环境选择合适的渠道。

- [GitHub Releases](https://github.com/niuzhix.Zinc/releases/)
